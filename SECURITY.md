# Security policy

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/marty-shields/app-ui-kit/security/advisories/new). Do not open a public issue for it.

Include the package and version (or commit), what you did and what happened. This is a personal project: expect a reply in a few days, and a fix in the next release where one is needed.

Only the latest release is supported.

The kit is a set of UI components, design tokens and a stories site. It stores no data and makes no network calls of its own.
